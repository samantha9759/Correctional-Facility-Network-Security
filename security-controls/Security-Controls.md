# Correctional Facility Security Controls

## Purpose

This document identifies recommended cybersecurity controls for the hypothetical correctional facility network architecture.

## 1. Identity and Access Management

**Risk Addressed:** Unauthorized account access and excessive privileges.

Recommended controls:
- Enforce Multi-Factor Authentication.
- Implement Role-Based Access Control.
- Apply least-privilege permissions.
- Disable inactive and terminated accounts.
- Review privileged accounts regularly.

## 2. Network Security

**Risk Addressed:** Unauthorized network access and lateral movement.

Recommended controls:
- Separate network zones based on business function.
- Apply restrictive firewall policies.
- Disable unnecessary network services.
- Review network access rules.
- Monitor unusual network activity.

## 3. Endpoint Security

**Risk Addressed:** Malware, ransomware, and unsupported systems.

Recommended controls:
- Maintain supported operating systems.
- Deploy endpoint detection and response.
- Apply security updates regularly.
- Restrict unauthorized software installation.
- Maintain endpoint security logs.

## 4. Security Monitoring

**Risk Addressed:** Delayed detection of suspicious activity.

Recommended controls:
- Centralize security logs.
- Monitor authentication failures.
- Review privileged account activity.
- Establish alerting for suspicious behavior.
- Maintain documented investigation procedures.

## 5. Backup and Recovery

**Risk Addressed:** Data loss and operational disruption.

Recommended controls:
- Maintain protected backups.
- Separate backup access from ordinary user accounts.
- Test restoration procedures.
- Document recovery responsibilities.
- Establish recovery priorities.

## 6. Control Validation

Security controls should be evaluated through:
- Periodic access reviews.
- Vulnerability assessments.
- Patch compliance checks.
- Backup restoration tests.
- Incident response exercises.
- Firewall rule reviews.

## Conclusion

Security controls should work together to protect information, restrict unauthorized access, detect suspicious activity, and support operational continuity.

The proposed controls are recommendations for a fictional environment and have not been deployed or independently validated.
