# Correctional Facility Network Modernization Budget

## Project Budget

**Total Proposed Budget: $50,000**

This budget represents an illustrative allocation for a hypothetical correctional facility network modernization project. Amounts are planning estimates, not vendor quotes.

| Category | Estimated Cost |
|---|---:|
| Network switches and infrastructure | $12,000 |
| Server and workstation modernization | $10,000 |
| Firewall and network security | $6,000 |
| Multi-Factor Authentication and identity management | $3,000 |
| Endpoint protection and centralized monitoring | $5,000 |
| Backup and disaster recovery | $4,000 |
| Security assessment and implementation | $5,000 |
| Contingency reserve | $5,000 |
| **Total** | **$50,000** |

## Budget Priorities

### 1. Network Infrastructure - $12,000
Modernize network infrastructure and support separation of administrative, operational, and restricted systems.

### 2. Server and Workstation Modernization - $10,000
Replace or upgrade unsupported systems to reduce exposure to known vulnerabilities.

### 3. Firewall and Network Security - $6,000
Improve network access restrictions and traffic control between security zones.

### 4. Identity Management - $3,000
Improve authentication and access management through MFA and role-based permissions.

### 5. Endpoint Protection and Monitoring - $5,000
Improve endpoint security visibility and centralized event monitoring.

### 6. Backup and Disaster Recovery - $4,000
Protect important information and support recovery following a disruption.

### 7. Security Assessment and Implementation - $5,000
Support planning, configuration, testing, documentation, and implementation activities.

### 8. Contingency - $5,000
Reserve funds for unexpected expenses and implementation needs.

## Budget Considerations

Actual project costs would depend on:
- Number of users and endpoints.
- Existing infrastructure.
- Licensing and subscription requirements.
- Hardware compatibility.
- Implementation labor.
- Vendor pricing.
- Ongoing maintenance costs.

## Conclusion

The proposed budget prioritizes infrastructure modernization, access control, endpoint protection, monitoring, and recovery.

A phased implementation approach would allow the organization to prioritize higher-risk systems while managing the available budget.

## Scope Disclaimer

This is a fictional planning budget created for educational and professional portfolio purposes. It is not a procurement quote or an approved facility expenditure.
